# Quick Reference Service List


|Service Name|Definition|
|---|---|
|**ANALYTICS**|
|Amazon Athena|Serverless query service that lets you analyse data stored in Amazon S3 using standard SQL. You pay per query, with no infrastructure to manage.|
|AWS Data Exchange|A service for finding, subscribing to, and using third-party datasets from data providers. It simplifies access to commercial and public datasets.|
|Amazon EMR|A managed big data platform used to process large datasets using frameworks such as Hadoop, Spark, Hive, and Presto. Ideal for analytics and machine learning workloads.|
|AWS Glue|A serverless data integration and ETL (Extract, Transform, Load) service. It helps prepare and move data between data stores for analytics.|
|Amazon Kinesis|A platform for collecting, processing, and analysing real-time streaming data. Commonly used for logs, IoT data, and application telemetry.|
|Amazon Managed Streaming for Apache Kafka (Amazon MSK)|A fully managed Apache Kafka service that makes it easy to build and run streaming applications. AWS handles cluster provisioning and maintenance.|
|Amazon OpenSearch Service|A managed search and analytics service based on OpenSearch and Elasticsearch technology. Commonly used for log analysis, monitoring, and full-text search.|
|Amazon QuickSight|AWS's business intelligence (BI) service for creating dashboards and visualisations. Enables users to explore and share insights from data.|
|Amazon Redshift|A managed, petabyte-scale data warehouse service designed for fast analytical queries across large datasets. Optimised for business intelligence and reporting.|
|**APPLICATION INTEGRATION**|
|Amazon EventBridge|A serverless event bus that routes events between AWS services, applications, and SaaS platforms. Enables event-driven architectures.|
|Amazon Simple Notification Service (Amazon SNS)|A publish/subscribe messaging service used to send notifications to multiple subscribers. Supports email, SMS, Lambda, SQS, and more.|
|Amazon Simple Queue Service (Amazon SQS)|A fully managed message queuing service used to decouple applications and microservices. Helps improve reliability and scalability.|
|AWS Step Functions|A workflow orchestration service that coordinates multiple AWS services into automated processes. Often used to build serverless applications.|
|**BUSINESS APPLICATIONS**|
|Amazon Connect|A cloud-based contact centre service that allows organisations to build customer support call centres. Supports voice, chat, and task management.|
|Amazon Simple Email Service (Amazon SES)|A scalable email service used for sending marketing, transactional, and notification emails. Supports both outbound and inbound email processing.|
|**CLOUD FINANCIAL MANAGEMENT**|
|AWS Billing Conductor|A service that enables customised billing views and chargeback models across AWS accounts. Useful for large organisations with multiple teams.|
|AWS Budgets|Allows organisations to set spending or usage thresholds and receive alerts when limits are approached or exceeded.|
|AWS Cost and Usage Report|Provides the most detailed AWS billing and usage data available. Often used for in-depth cost analysis and reporting.|
|AWS Cost Explorer|A visual tool for analysing historical AWS spending and forecasting future costs. Helps identify trends and optimisation opportunities.|
|AWS Marketplace|An online catalogue where customers can purchase and deploy third-party software, data products, and services that run on AWS.|
|**COMPUTE**|
|AWS Batch|A service for running batch computing jobs at any scale. AWS automatically provisions the required compute resources.|
|Amazon EC2|Provides resizable virtual servers in the cloud. Users have control over operating systems, applications, and configurations.|
|AWS Elastic Beanstalk|A Platform as a Service (PaaS) offering that deploys and manages web applications automatically. Developers simply upload their code.|
|Amazon Lightsail|A simplified cloud platform offering virtual servers, databases, and networking with predictable pricing. Ideal for small projects and learning environments.|
|AWS Local Zones|Extends AWS infrastructure closer to major population centres to reduce latency for applications requiring fast local processing.|
|AWS Outposts|Brings AWS infrastructure and services into an organisation's on-premises data centre. Provides a consistent hybrid cloud experience.|
|AWS Wavelength|Deploys AWS services at the edge of 5G networks to deliver ultra-low latency mobile applications.|
|**CONTAINERS**|
|Amazon Elastic Container Registry (Amazon ECR)|A managed container image registry for storing, managing, and securing Docker container images.|
|Amazon Elastic Container Service (Amazon ECS)|AWS's native container orchestration platform for deploying and managing containerised applications.|
|Amazon Elastic Kubernetes Service (Amazon EKS)|A managed Kubernetes service that simplifies running Kubernetes clusters on AWS.|
|**CUSTOMER ENGAGEMENT**|
|AWS Activate for Startups|Provides startups with AWS credits, training, support, and business resources to accelerate cloud adoption.|
|AWS IQ|Connects customers with AWS-certified freelancers and consultants who can assist with AWS projects.|
|AWS Managed Services (AMS)|An operational service where AWS manages infrastructure according to best practices for security, reliability, and compliance.|
|AWS Support|Provides technical assistance and guidance through various support plans ranging from Basic to Enterprise.|
|**DATABASES**|
|Amazon Aurora|A cloud-native relational database compatible with MySQL and PostgreSQL. Designed for high performance and availability.|
|Amazon DynamoDB|A fully managed NoSQL database offering single-digit millisecond performance at virtually any scale.|
|Amazon MemoryDB for Redis|An in-memory Redis-compatible database that provides fast performance with durable data storage.|
|Amazon Neptune|A managed graph database service designed for highly connected datasets such as social networks and recommendation engines.|
|Amazon RDS |A managed relational database service supporting engines such as MySQL, PostgreSQL, Oracle, and SQL Server.|
|**DEVELOPER TOOLS**|
|AWS AppConfig|A feature management and configuration service that enables safe deployment of application settings without code changes.|
|AWS CLI|A command-line tool for managing AWS services through scripts and terminal commands.|
|AWS Cloud9|A cloud-based integrated development environment (IDE) with browser-based coding and debugging tools.|
|AWS CloudShell|A browser-based shell preconfigured with AWS tools and credentials for managing AWS resources.|
|AWS CodeArtifact|A managed artifact repository used to store and share software packages and dependencies.|
|AWS CodeBuild|A fully managed service that compiles source code, runs tests, and produces deployment artifacts.|
|AWS CodeCommit|A fully managed Git-based source control repository service.|
|AWS CodeDeploy|Automates software deployments to EC2 instances, Lambda functions, and on-premises servers.|
|AWS CodePipeline|A continuous integration and continuous deployment (CI/CD) service that automates release pipelines.|
|AWS CodeStar|A service that helps teams quickly set up and manage software development projects on AWS.|
|AWS X-Ray|Provides distributed tracing to help developers analyse and troubleshoot application performance issues.|
|**END USER COMPUTING**|
|Amazon AppStream 2.0|A fully managed application streaming service that delivers desktop applications through a web browser.|
|Amazon WorkSpaces|A managed Desktop-as-a-Service (DaaS) solution providing cloud-hosted virtual desktops.|
|Amazon WorkSpaces Web|A secure browser service that allows users to access websites and web applications without exposing local devices.|
|**FRONTEND WEB AND MOBILE**|
|AWS Amplify|A platform for building, deploying, and hosting web and mobile applications with AWS services.|
|AWS AppSync|A managed GraphQL service that enables applications to securely access and synchronise data from multiple sources.|
|AWS Device Farm|A testing service that runs mobile and web applications on real devices in the AWS cloud.|
|INTERNET OF THINGS (IOT)|
|AWS IoT Core|Allows connected devices to securely communicate with AWS and other devices.|
|AWS IoT Greengrass|Extends AWS functionality to edge devices, enabling local processing and offline operation.|
|**MACHINE LEARNING**|
|Amazon Comprehend|Uses natural language processing (NLP) to extract insights and meaning from text.|
|Amazon Kendra|An intelligent enterprise search service powered by machine learning.|
|Amazon Lex|A conversational AI service used to build chatbots and voice assistants.|
|Amazon Polly|Converts text into lifelike speech using AI-generated voices.|
|Amazon Rekognition|Provides image and video analysis capabilities such as object, face, and activity detection.|
|Amazon SageMaker|A comprehensive platform for building, training, and deploying machine learning models.|
|Amazon Textract|Automatically extracts text, forms, and tables from documents.|
|Amazon Transcribe|Converts speech into text using automatic speech recognition.|
|Amazon Translate|Provides neural machine translation between multiple languages.|
